# Teams Excuse Generator
An easy way to generate random excuses and copy them to people you dislike, but have to like.

## What does it do?

It is a Tkinter window that can:

- generate a random excuse when you press the button
- copy the message so you don't have to do it yourself #lazy
- temporarily improve your quality of life
- give you an excuse to decline anything

Although, there is a bug. If you press the copy button while on the welcome message, it will copy the welcome message. I will eventually fix this. Maybe. Probably. I'm sure I will.
